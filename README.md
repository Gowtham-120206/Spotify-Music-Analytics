🎵 Spotify Music Analytics Dashboard

📊 Project Overview

This project is an interactive Spotify Music Analytics Dashboard built using Microsoft Power BI.

The dashboard helps analyze music streaming data based on artists, genres, countries, release years, tracks, and popularity.

🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

📌 Key KPIs

- 🎧 Total Streams: 6B
- 🎤 Total Artists: 500
- 🎵 Total Tracks: 9K
- ⭐ Average Popularity: 28.14

📈 Dashboard Features

- Annual Streaming Trend
- Top 10 Artists by Streams
- Top 10 Genres by Streams
- Top 10 Countries by Streams
- Release Year Analysis
- Genre Filter
- Country Filter
- Interactive Power BI visuals

🎯 Key Insights

The dashboard provides a clear view of streaming performance and helps identify:

- Most streamed artists
- Popular music genres
- Countries with higher streaming activity
- Year-wise streaming trends
- Overall music popularity
